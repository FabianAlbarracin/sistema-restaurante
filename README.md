# Sistema de restaurante

Proyecto mínimo desarrollado para diseñar y probar un pipeline de integración continua con Jenkins.

## Funcionalidades

- Cálculo del total de un pedido.
- Registro y consulta de reservas.
- Validación de datos básicos.
- Pruebas automatizadas con pytest.

## Requisitos

- Python 3.12
- pytest
